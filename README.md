# Synthetic-Data-Generator
This project aims to generate synthetic data for testing machine learning algorithms, statistical analysis, and model development. It uses various techniques to simulate realistic datasets with customizable features, such as regression, classification, time-series, and categorical data. The project is implemented in Google Colab to allow users to easily generate synthetic data in the cloud, without requiring complex setup.

Project Overview
The Synthetic Data Generator allows you to generate realistic datasets for a variety of use cases. Whether you are working on training machine learning models, testing statistical algorithms, or need datasets for educational purposes, this tool helps you create synthetic data that mimics real-world scenarios. The generator is highly customizable, letting you define the size, features, and relationships within the data.

Key Features:
Regression Data: Generate synthetic datasets for linear, non-linear, and multivariate regression problems.
Classification Data: Create labeled data for classification tasks, including binary and multi-class classification.
Time Series Data: Generate time-series data with trends, seasonality, and noise for time-series forecasting models.
Categorical Data: Generate datasets with categorical features and labels, useful for classification tasks.
Noise Addition: Optionally add random noise to the data to simulate real-world imperfections.
Google Colab Integration: Easily run the notebook in Google Colab for cloud-based experimentation without local setup.
